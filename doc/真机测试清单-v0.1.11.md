> 适用包：`niudbm-0.1.11-amd64.fpk`（x86）、`niudbm-0.1.11-arm64.fpk`（ARM）

## 2. 默认配置内容（本版重点）

| # | 步骤 | 预期 |
| --- | --- | --- |
| 2.1 | **新建**一个服务，进「配置文件」 | 内容不再只有两行：有 `[mysqld]` 段头 + 3 行说明注释 + 若干分组 |
| 2.2 | 看分组 | 至少包含「连接与超时」「InnoDB：内存与刷盘」「临时表与缓冲」「字符集与表名」「慢查询」几组，每组前有 `# ---- 标题 ----` |
| 2.3 | 看具体参数 | 如 `max_connections = 151`、`innodb_buffer_pool_size = 128M`、`character_set_server = utf8mb4` 等，值都是默认值 |
| 2.4 | 老服务（0.1.10 之前建的）进「配置文件」 | 顶部出现黄色提示"这个文件几乎是空的（早期版本创建时只写了段头）" |
| 2.5 | 点「载入推荐模板」 | 确认后编辑器被完整模板填满，标出「未保存」 |
| 2.6 | 点「保存配置文件」→「重启生效」 | 服务重启，`SELECT @@max_connections` 等与文件里一致 |
| 2.7 | 再回「配置」页改一个参数保存 | 回到配置文件页，文件被整份重写（分组的标题注释仍在，手写注释会丢） |

## 4. 列表分页（六处）

每处都验：翻页、改每页条数、搜索后回到第 1 页。

| # | 位置 | 预期 |
| --- | --- | --- |
| 4.1 | 数据库服务（卡片/表格） | 底部有「共 N 条 · 10 条/页 · 上一页 · 1 / 2 · 下一页」 |
| 4.2 | 服务里的「数据库与账号」→ 库列表 | 同样有翻页条，表格与卡片视图都生效 |
| 4.3 | 用户抽屉 | 表格下方有翻页条；搜索后自动回到第 1 页 |
| 4.4 | 备份与恢复 | 表格与卡片视图都有翻页条；删除某条后条数刷新 |
| 4.5 | 任务中心 | 切换状态筛选后回到第 1 页；表格与卡片视图都生效 |
| 4.6 | 操作记录 | 切换"最近 50/100/300 条"后重新分页，默认 20 条/页 |
| 4.7 | 任一处把每页改成 50 条 | 立即生效并回到第 1 页 |
| 4.8 | 数据少于 1 页时 | 只显示「共 N 条」，上一页/下一页都置灰 |
| 4.9 | 手机宽度 | 翻页条自动换行，按钮不会被挤成一条缝 |
| 4.10 | 镜像页 | **没有**分页（固定 9 个版本，属于清单不是列表），符合预期 |

## 6. 出包前跑过的验证

- 前端 `vue-tsc --noEmit` + `vite build` 通过（1672 modules）。
- 后端 `gofmt` / `go vet` / `go test -count=1 ./...` 全绿。
- 容器冒烟 20 项全绿，其中「配置文件原文读写、空内容拦截与恢复上一版」覆盖：读 → 参数页保存 → 手写 300 → 备份出现 → 空内容 400 → 恢复回 200。
- 本版新增的 `renderCnf` 分组渲染由该冒烟间接覆盖（参数页保存后读回内容仍能匹配 `max_connections = 200`）。
