# 牛库管家 v0.1.8 真机测试清单 · 用户表单改弹窗 + 密码列排版

> 适用包：`niudbm-0.1.8-amd64.fpk`（x86）、`niudbm-0.1.8-arm64.fpk`（ARM）
> 直接覆盖 0.1.7，不用卸载。
> 这一版只动界面：验两件事——新增/编辑是不是弹窗、密码明文后按钮还看不看得见。

---

## 1. 新增/编辑改弹窗

| # | 步骤 | 预期 |
| --- | --- | --- |
| 1.1 | 服务详情 →「用户」 | 抽屉打开，**只有列表**，上方不再有内嵌的表单卡片 |
| 1.2 | 点「新建用户」 | 弹出居中弹窗（标题「新建用户」），抽屉仍在背后；弹窗不再把列表往下挤 |
| 1.3 | 看弹窗宽度 | 桌面上约 720px；把窗口拉窄或手机上接近全宽，不出现横向滚动 |
| 1.4 | 弹窗里填用户名、密码，选来源、选库 →「创建」 | 创建成功，弹窗关闭，列表已刷新并出现新用户 |
| 1.5 | 点列表行里的「编辑」 | 弹出同一个弹窗，标题是「编辑 用户名」 |
| 1.6 | 编辑里改来源后「保存」 | 保存成功，弹窗关闭，列表更新 |
| 1.7 | 弹窗里点「取消」/ 右上角 × / 按 ESC | 关闭且不保存；再点「新建用户」是干净的空表单（不会带上一次的残留内容） |
| 1.8 | 点弹窗外的遮罩 | 不会误关（已禁用点遮罩关闭），避免填一半丢失 |
| 1.9 | 弹窗里的来源输入框回车添加、非法值提示 | 与 0.1.7 行为一致（见 [真机测试清单-v0.1.7](./真机测试清单-v0.1.7.md) 第 1 节） |
| 1.10 | 弹窗打开时看背后的抽屉 | 抽屉的层级仍在弹窗之下，弹窗内容不被遮挡 |

## 2. 密码列排版（本版主诉）

| # | 步骤 | 预期 |
| --- | --- | --- |
| 2.1 | 列表默认状态 | 密码列显示 `••••••••`，后面两个图标按钮（眼睛、复制）完整可见 |
| 2.2 | 点眼睛看明文（20 位随机密码那种长密码） | 明文**折行显示**，后面的眼睛、复制按钮**仍然完整可见**，没有被挤出去 |
| 2.3 | 把鼠标停在明文上 | 悬停提示里是完整密码 |
| 2.4 | 点复制 | 复制到的是完整明文，与悬停提示一致 |
| 2.5 | 再点一次眼睛 | 回到 `••••••••`，按钮位置不跳 |
| 2.6 | 一个很长密码（如 40 位，用外部工具建的账号） + 其他工具创建时 | 明文折成 3 行左右，按钮依然在列内可见 |
| 2.7 | 抽屉宽度 | 比 0.1.7 宽一些（720px），「用户 / 密码 / 数据库 / 操作」四列都能完整显示，底部无横向滚动条 |
| 2.8 | 手机（≤720px）打开用户抽屉 | 抽屉接近全宽；密码列与按钮仍能看全，表格可横向滑动 |
| 2.9 | 系统账号（root 等）行 | 密码按钮照旧可用/不可用逻辑不变，排版不塌 |

## 4. 这一版故意没做

- 用户列表没有改成分页或虚拟滚动（账号量在 NAS 场景下通常几十个，够用）。
- 密码列没有做"点击整列展开/收起"，仍是一个账号一个眼睛。
- 弹窗没有做"保存后停留在弹窗连续建号"的批量模式。
