# 真机测试清单 v1.0.0

> x86 和 ARM 安装包都要测试。

## 安装与升级

- [ ] 从飞牛应用中心安装 `amd64` 与 `arm64` 包。
- [ ] 应用内版本显示 `1.0.0`。
- [ ] 首次启动没有目录、权限或 Socket 错误。
- [ ] 管理员和普通成员都能从飞牛桌面进入。

## 权限

- [ ] 普通成员只看到被授权服务。
- [ ] 只读成员看不到凭据和写操作。
- [ ] 运维者可以启停、建库、建号、备份。
- [ ] 服务管理员可以管理成员和删除服务。
- [ ] NAS 管理员可以管理全部服务。

## MySQL / MariaDB

- [ ] 创建 MySQL 与 MariaDB 服务成功。
- [ ] 数据库、账号、四档权限和连接信息正常。
- [ ] 配置文件符合对应版本，不含 `lower_case_table_names`。
- [ ] 参数修改、重启提示和备份恢复正常。

## PostgreSQL

- [ ] 创建 PostgreSQL 15/16/17 服务成功。
- [ ] 数据库与账号正常。
- [ ] `postgresql.conf`、`pg_hba.conf` 可编辑并 reload。
- [ ] `postgresql.auto.conf` 只读。
- [ ] `pending_restart` 提示正确。
- [ ] 备份恢复正常。

## MongoDB

- [ ] 创建 MongoDB 6/7/8 服务成功。
- [ ] root 连接串包含 `authSource=admin`。
- [ ] 数据库、集合、账号和角色正常。
- [ ] `mongod.conf` 可见，默认固定 `/data/db`、`27017` 和认证开启。
- [ ] 修改危险配置会被拒绝。
- [ ] 修改合法配置后重建容器，数据保留。
- [ ] gzip archive 备份恢复成功。

## 外部连接

- [ ] MySQL、PostgreSQL、MongoDB 外部连接测试成功。
- [ ] 连接失败不留下台账记录。
- [ ] 外部数据库不显示容器启停、配置文件和本应用备份。
- [ ] 移除连接不会修改外部数据库。

## 页面

- [ ] PC 侧栏、手机底栏和路由正常。
- [ ] 刷新 `/app/niudbm/databases/{id}/{tab}` 正常。
- [ ] 镜像页 MySQL、PostgreSQL、MongoDB 页签都显示版本。
- [ ] 未拉取镜像与清单为空能明确区分。
- [ ] 备份中心、任务中心、操作记录和设置正常。

## 安全

- [ ] 外部连接密码不是明文。
- [ ] 只读成员无法取回密码。
- [ ] 删除服务需要名称确认。
- [ ] Webhook 审计不包含完整地址。
- [ ] 配置文件和审计不包含数据库密码。
