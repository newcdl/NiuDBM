# 牛库管家 v0.1.7 真机测试清单 · 用户表单 + 大屏排版 + 镜像管控

> 适用包：`niudbm-0.1.7-amd64.fpk`（x86）、`niudbm-0.1.7-arm64.fpk`（ARM）

## 5. 这一版故意没做

- **离线 tar 导入镜像**（`docker load`）：界面上还看不到，只能在宿主上用命令导入。
- **连接二维码**：手机扫码连库没有做。
- 容器健康检查与启动超时重试（路线图 M1 剩余项）留到下一版。
- 监控曲线（CPU/内存/连接数随时间变化）没有；配置页的「当前状态」仍是快照。
- 「访问来源」仍不支持主机名，这是刻意的（`skip-name-resolve` 下没用）。
- 大屏只做"有上限 + 居中 + 字号上调"，没有做多栏仪表盘式重排。

## 6. 出包前跑过的验证

- 前端 `vue-tsc --noEmit` + `vite build` 通过（1662 modules）。
- 后端 `gofmt` / `go vet` / `go test -count=1 ./...` 全绿。
- 容器冒烟（真 Docker + 真 MySQL 8.4）20 项全绿，本版新增 1 项：
  - `镜像占用统计、在用时禁删、已存在免拉取`：部署后 `GET /images` 的 `usedBy` 里是该服务名、`local=true`；`DELETE /images/8.4` 返回 409 且提示"N 个服务在用"；再次 `POST /images/pull` 回 `cached:true`；不存在的版本 400。
- 新增单测 `roles_test.go`（网段换算）与 `hostrule.ts`（前端解析）覆盖同一套规则，两边对 `/0`–`/32`、点分掩码、非法掩码的判断一致。
