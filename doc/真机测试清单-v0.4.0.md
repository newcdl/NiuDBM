## 0. 本次交付是什么

v0.3.0 对功能范围做了一次纠偏：这个应用管的是**数据库的配置、用户、备份、导入导出和引擎**，不再做表结构浏览与 SQL 控制台。

| 能力 | 说明 |
| --- | --- |
| 建库 | SQLite、PostgreSQL（16.2 / 17.11）、MySQL（MariaDB 11.4.5 / 10.11.19）；PG / MySQL 建库时可一并创建接入账号、并指定用哪个引擎版本 |
| 概览 | 版本、状态、数据目录、端口、连接串（不含密码），密码单独显示与复制 |
| 配置 | PostgreSQL：10 项常用参数，走 `ALTER SYSTEM` + reload；重启级参数会明确提示。MySQL：`my.cnf` 白名单，保存后需重启实例生效。SQLite：PRAGMA 白名单，每次连接生效 |
| 用户 | PostgreSQL / MySQL 库级四档：只读 / 读写 / 全权 / 无权限；支持建号、改密码、改权限、删号；超级用户与引擎保留名受保护。SQLite 无用户体系，页面说明文件权限 |
| 备份与恢复 | SQLite 用 `VACUUM INTO` 一致性快照；PostgreSQL 用冷备（停库→打包数据目录→起库）；MySQL 用 `mariadb-dump` 逻辑备份（原本停着的实例备份期间临时启动，完成后回到停止）；备份落在飞牛共享目录，可下载 |
| 导入导出 | 普通 SQL 脚本导入；CSV 按表导入/导出（`\N` 表示 NULL，空字段是空字符串，导出带 UTF-8 BOM） |
| 引擎 | 引擎**不随安装包分发**：引擎页按版本在线下载（官方镜像 + SHA256 校验）或导入本地归档，按版本并存、可单独卸载（有实例依赖时禁止）；页首给出安装前体检（端口占用、系统已有数据库、Docker、磁盘） |
| 审计 | 建库、配置修改、导入导出、用户增删改、引擎安装/修复/卸载、启停、备份恢复全部留痕 |

刻意**没有**做（不要当缺陷报）：

- **同一引擎可并存多个版本，但没有自动升级**：PostgreSQL 16→17、MariaDB 11.4→更高版本升级要新建实例搬数据（数据目录格式随大版本变化）。
- **清单外的版本靠导入**：安装器会校验归档结构，但不校验 SHA256（清单里没有该版本）。
- MySQL 引擎在 ARM 上没有官方包：MariaDB 官方不发布 arm64 二进制包，ARM 机器只能用「导入自编译归档」。
- SQL 脚本导入是"逐条执行普通语句"，不是 pg_dump/psql 兼容层：不支持 `COPY ... FROM stdin`、`\` 开头的 psql 元命令、自定义格式（`-Fc`）备份文件；MySQL 侧同样不支持 `mysql` 客户端元命令（`source`、`delimiter` 等）。
- PostgreSQL 的 "全权"档位只能管理**自己拥有的**对象，不能接管其他人建的表；降级也不会夺走该账号已拥有对象的固有权限。
- 备份互斥在实例级：PostgreSQL 冷备期间该实例会短暂停止，备份完成后自动启动；MySQL 逻辑备份不停库，但原本停着的实例会被临时拉起。
- 没有成员权限、跨实例迁移、多引擎（Redis）；定时备份已支持（见 6A 节）。

## 1. 安装前

1. 确认 CPU 架构，决定装哪个包：

```bash
uname -m            # x86_64 → amd64 包；aarch64 → arm64 包
```

2. 包体积很小，因为**引擎不在包里**：安装包只有程序与前端（amd64 约 27MB、arm64 约 25MB）。
   第一次用某个引擎时，在「引擎管理」里下载（PostgreSQL 15MB、MariaDB 349MB）或导入归档，
   装完解出来 PostgreSQL 约 58MB、MariaDB 约 760MB。完整说明见 `doc/引擎获取与安装指南.md`。

3. P0：SQLite 实例（约 5 分钟）

| # | 步骤 | 预期 |
| --- | --- | --- |

## 10. 附录：绕过界面直接打接口（curl）

界面已经全部接真实接口；下面这些命令用于排查问题时绕过界面直接验证。
下面的命令都在 fnOS 上以 root 执行：

```bash
SOCK=/var/apps/niudbm/target/app.sock
API=http://localhost/app/niudbm/api/v1
# 直连 socket 时自己带身份头；走网关时这两行由平台注入，不要手工伪造
C() { curl -sS --unix-socket "$SOCK" -H 'X-Trim-Userid: 1000' -H 'X-Trim-Username: admin' -H 'X-Trim-Isadmin: true' "$@"; }
```

```bash
# 1. 引擎清单：每个版本 installed / available / unavailable，带校验和
C "$API/engines"

# 2. 安装前体检：端口占用、系统已有数据库、Docker、磁盘
C "$API/preflight"

# 3. 在线下载并安装（返回 taskId，用第 4 步看进度）
C -X POST "$API/engines/mysql/download" -H 'Content-Type: application/json' -d '{"version":"11.4"}'

# 4. 查安装进度：download → extracting → done / failed
C "$API/engine-tasks/<taskId>"

# 5. 离线导入（请求体就是归档本身，版本号走查询参数）
C -X POST "$API/engines/mysql/import?version=11.4" \
  -H 'Content-Type: application/octet-stream' --data-binary @mariadb-11.4.5-linux-systemd-x86_64.tar.gz

# 6. 建一个 MySQL 库，指定引擎版本，同时建只读账号
C -X POST "$API/instances" -H 'Content-Type: application/json' \
  -d '{"name":"测试库","engine":"mysql","engineVersion":"11.4","users":[{"name":"app_ro","password":"Passw0rd_42","level":"read"}]}'

# 7. 卸载某个引擎版本（有实例依赖会被拒绝；实例数据不动）
C -X DELETE "$API/engines/mysql/11.4"

# 8. 用返回的 id 依次看：连接信息（含密码）、用户、配置
ID=<上一步返回的 id>
C "$API/instances/$ID/connection"
C "$API/instances/$ID/users"
C "$API/instances/$ID/config"

# 9. 改配置：reload 级立即生效，restart 级返回 needRestart=true
C -X PUT "$API/instances/$ID/config" -H 'Content-Type: application/json' \
  -d '{"values":{"max_connections":"64"}}'

# 10. 导入 SQL、导出 CSV、备份、恢复
C -X POST "$API/instances/$ID/import/sql" -H 'Content-Type: text/plain' \
  --data-binary "CREATE TABLE t (id INT PRIMARY KEY, v TEXT); INSERT INTO t VALUES (1,'hello');"
C "$API/instances/$ID/tables"
C "$API/instances/$ID/export?table=t" -o /tmp/t.csv
C -X POST "$API/instances/$ID/backups" -H 'Content-Type: application/json' -d '{"note":"手动备份"}'
C -X POST "$API/instances/$ID/backups/<备份 id>/restore" -H 'Content-Type: application/json' \
  -d '{"confirmName":"测试库"}'

# 11. 审计与自检
C "$API/audit?limit=50"
C "$API/diag"
```

几条约定，避免误判：

- `X-Trim-Isadmin: true` 只在直连 socket 时有效，用来免去平台网关鉴权；**不要**把这个能力暴露到公网。
- 建库请求里的密码只出现在响应里一次，接口与审计都不会再返回明文。
- 想验证权限是否真的生效，用客户端（DBeaver / mysql / psql）以接入账号连实例端口，而不是看界面。
