# 开发与验证

## 环境

- Go 1.24+
- Node.js 20+
- pnpm
- fnpack（生成飞牛安装包）
- Docker（真机前验证托管服务时需要）

## 开发

后端：

```bash
cd server
go run ./cmd/niudbm --addr 127.0.0.1:8780 --prefix /app/niudbm
```

前端：

```bash
cd web
pnpm install
pnpm dev
```

## 自动化验证

```bash
cd server
go vet ./...
go test -count=1 ./...

cd ../web
pnpm exec vue-tsc --noEmit
pnpm build
```

测试重点：

- 身份会话和服务级权限隔离。
- 外部数据库连接与凭据加密。
- MySQL/MariaDB、PostgreSQL、MongoDB 文件与版本差异。
- 备份、恢复、定时策略、任务取消与持久化。
- PC、手机、网关前缀深链和静态资源。

## 双架构构建

```bash
scripts/build.sh --pack
```

产物：

```text
dist/niudbm-<version>-amd64.fpk
dist/niudbm-<version>-arm64.fpk
```

构建脚本会校验：

- manifest 与生命周期脚本。
- 前端产物是否内嵌。
- Go 测试和 vet。
- 二进制架构与静态链接。
- 包内 manifest.platform。
- SHA-256 校验文件。

## 冒烟测试

有 Docker 的 Linux 环境：

```bash
scripts/smoke.sh dist/niudbm-linux-amd64 amd64
scripts/smoke.sh dist/niudbm-linux-arm64 arm64
```

没有 Docker 时脚本会明确返回“跳过”，不能把跳过当成通过。
